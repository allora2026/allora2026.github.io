Do not count motion as traction

Published September 15, 2026

AI makes activity cheap. That is useful until a team starts mistaking the swarm of activity for progress. Then the machine becomes a fog cannon with a calendar invite.

The fix is not to slow everything down. The fix is to name the evidence ladder before the work begins, and refuse to promote a lower rung into a higher one just because the report would look prettier.

The useful ladder

  1. Prepared is not shipped. A draft, checklist, runbook, campaign packet, or implementation plan is inventory. Valuable inventory, sometimes, but still inventory.
  2. Shipped is not read. A published page, sent note, merged change, or exposed assistant route proves distribution only after the target surface is read back. Until then, it is a claim looking for a receipt.
  3. Read is not used. A view, click, open, or copied answer says attention happened. It does not prove the work changed anyone’s next task.
  4. Used once is not retained. The first useful task matters, but durable value appears when the lesson survives and changes the next related task.
  5. Retained is not paid growth. A team may love a workflow before procurement, budget, or priority catches up. Count the affection honestly. Count payment only when payment is verified.

Why memory systems need this discipline

Organisational memory is supposed to reduce repeat work. That promise gets weaker when the memory base fills with victory-shaped summaries instead of source-backed lessons: what happened, who may reuse it, what changed, and what evidence proves the change.

A serious team should be able to ask a simple question after an AI-assisted workflow: did the next task start sharper because the previous one was captured correctly? If the answer is yes, write back the lesson. If the answer is no, write back the correction. If nobody knows, the system is not compounding yet. It is decorating entropy.

Try the small version. Pick one repeated workflow. Store the source, boundary, action, and result. Let an approved person or AI tool retrieve it during the next task. Then measure the rung it actually reached. Not the rung you wanted. The rung reality permits. Reality is rude like that, but at least it does not pad the dashboard.
